## Agreed final deliverables

1. The DataSage command-line tool for one CSV or Excel table, a question and an optional rules file,
   with the five Milestone 1 outputs: quality report, change log, cleaned copy, answer with caveats, and
   replay script.
2. A Streamlit page for the demo.
3. Reusable cleaning recipes.
4. A final evaluation on the held-out tasks plus real messy files.
5. His ratings of 10 reports and an acceptance test.

**Out of scope:** joins across tables, unstructured data, machine learning, writing back to the source,
near-duplicate rows and the code sandbox. Trusted-document retrieval only if time allows.

## Agreed success criteria

| Metric | Target |
|---|---|
| Answer accuracy on the held-out tasks | at least 90% |
| Damaged valid data | zero |
| Detection precision / recall | at least 0.85 / at least 0.80 |
| Planted errors handled | at least 80% |
| Completion and tool-call success | at least 95% |
| Approvals per question | at most 3 |
| Time per question, small model | at most 60 s |
| Cost | reported in tokens |
| Acceptance test | 3 test files reach at least 90% answer accuracy with no valid data corrupted |
