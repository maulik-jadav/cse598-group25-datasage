Headline

An LLM agent that checks, fixes and asks before it answers gets 95.5% of 200 unseen questions on messy tables right, against 46.5% for a single LLM call, and never damaged a valid cell.

01

Problem

#SILENT!
Messy CSV and Excel files quietly change answers.
#MISSED!
Fixed cleaning scripts miss things they were not written for.
#NOLOG!
A single LLM call edits data it shouldn't and leaves no record.
02

How it works

INPUT
File + question
CSV or Excel, plus what the user wants to know
→
PLANNER · LLM
Pick next step
Chooses the next check or fix to run
→
APPROVAL GATE
Ask the user
Risky fixes wait for the user
→
TOOLS
Apply + validate
Run the step, verify the result, log it
→
CHECK
Coverage check
Has every column the question needs been checked?
→
OUTPUT
Answer + report
The answer with a full record of every change
▲
not covered yet → plan the next step
